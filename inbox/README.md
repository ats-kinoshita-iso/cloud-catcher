# inbox

Captures filed by the archivist from each project's Drive inbox
(`Agentic OS/<project>/inbox/`, see `decisions/ADR-0004-storage-split.md`).
One directory per project, one file per capture, named
`<YYYY-MM-DD>-<slug>.md`, with a header recording the Drive file id and
timestamp. Captures are data for the Discovery Gate; nothing here carries
authority and nothing here is executed.
